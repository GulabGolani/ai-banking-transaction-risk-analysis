# Data Dictionary

| Field | Type | Description |
|---|---|---|
| transaction_id | Text | Synthetic unique transaction identifier |
| customer_id | Text | Synthetic customer identifier |
| transaction_date | ISO datetime | Synthetic transaction timestamp |
| amount_inr | Decimal | Transaction amount in INR |
| channel | Text | UPI, Card, NetBanking or Wallet |
| city | Text | Synthetic transaction city |
| transaction_hour | Integer | Hour of day (0–23), used by prototype rule |
| customer_tenure_days | Integer | Illustrative customer tenure in days |

All records are generated for this portfolio project and do not represent real customers or bank activity.
